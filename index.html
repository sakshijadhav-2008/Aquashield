System Architecture

Pipeline

Electrode sensor → LM358 comparator (signal conditioning) → ESP32 (analog read + threshold logic, GPIO34) → local alert (LED, GPIO2) + Blynk Cloud (virtual pin V0 + logEvent) → push notification on the Blynk mobile app.

Software Layers

1. Firmware layer — Wokwi-simulated ESP32 sketch (aquashield_blynk.ino), sensor sampling + threshold logic.
2. Cloud layer — Blynk.Cloud datastream (V0) and event automation (leak_alert) for real push notifications.
3. Dashboard layer — this web app: live monitoring, multi-node device view, history, analytics and settings, modeling the end-user control panel.

Why software-based

Full simulation + real cloud alert pipeline demonstrates complete system logic and IoT integration without dependency on physical part availability, while remaining fully portable to real hardware (LM358 + ESP32 + electrodes) with no logic changes.
